# Rock, Paper, Scissors

A browser-based Rock–Paper–Scissors game built with vanilla JavaScript.

Pick rock, paper or scissors with the buttons and play against the computer. The score board updates after every round, and the first to reach 5 points wins. The game then announces the result and resets.

## Features

- Computer choice picked at random
- Round result and running score shown on the page
- First to 5 wins, with a win/lose message and automatic reset
- Responsive dark UI that works on phone and desktop

## Built With

- HTML
- JavaScript (DOM events, functions, control flow)
